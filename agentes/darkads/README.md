# Agentes do projeto DarkAds

Agentes de apoio em rascunho para o projeto. Eles auditam e propõem; implementação, mudança de copy, merge e publicação dependem de autorização do Alex.

| Agente | Função | Estado |
| --- | --- | --- |
| [Auditor visual de referência](auditor-visual.md) | Captura estados desktop/mobile, compara a experiência e registra diferenças observadas | Rascunho para aprovação |
| [Construtor Base44](base44-builder.md) | Usa as skills oficiais do Base44 para preparar uma implementação e uma lista de melhorias opcionais | Rascunho para aprovação |

Skills relacionadas: [auditoria de referência](../../.agents/skills/darkads-reference-audit/SKILL.md) e [workflow Base44](../../.agents/skills/base44-darkads-landing/SKILL.md).
