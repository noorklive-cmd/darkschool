# Sites

- [Framer da Dark School](https://landing-page-dark-school.framer.ai/) — referência do site existente. A cópia do projeto no editor depende do acesso ao Framer.
- [Dark Tap](dark-tap/index.html) — HTML original importado, com CSS, JavaScript e imagens. É uma versão de referência que ainda usa a marca Alex Designer Lab e mostra um preço de matéria-prima. O material serve de base para a nova oferta Dark Tap. Consulte a [decisão de produto](../produtos/dark-tap.md) antes de publicar.
- [Botões](exemplos/botoes/index.html) — demo estática reutilizável. Abra o arquivo no navegador ou rode `python3 -m http.server 8080` na raiz e acesse `/sites/exemplos/botoes/`.
