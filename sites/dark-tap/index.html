Perguntas frequentes

Preciso ter um site?

Você pode usar um endereço que já tem, como seu WhatsApp, o cardápio online ou seu link de avaliação no Google.

O cliente precisa baixar um aplicativo?

O cartão com link pode abrir pelo próprio celular quando o aparelho é compatível com leitura NFC. A forma de abrir varia conforme o modelo e as configurações.

Posso usar o mesmo cartão se o link mudar?

Sim, se gravarmos um endereço fixo que redireciona para o destino. Com o link gravado diretamente, é preciso regravar o cartão.

O painel da demonstração já está disponível?

O painel do lojista nesta página é uma simulação. Fale com a Dark School para saber quais configurações estão disponíveis para o seu cartão.
