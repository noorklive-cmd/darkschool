# Design

Preto, branco e grafite formam a base. Use cor de destaque em poucos pontos de ação. A hierarquia vem de tipografia, contraste e espaçamento. Reserve animações para transições e feedback de interação. Teste no celular e com movimento reduzido.

[Amostra HTML de botões](../sites/exemplos/botoes/index.html). Tokens e rótulos da demo são exemplos para adaptação.
