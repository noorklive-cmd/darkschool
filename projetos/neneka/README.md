# Neneka — site artístico

Projeto exclusivo para a apresentação artística da Neneka.

## Direção

Brutalismo moderno com base Dark School: alto contraste, tipografia display condensada, composição assimétrica, textura de xerox/ruído, blocos de informação, vermelho ácido como cor de choque e ritmo visual inspirado em pôster de rua, encarte underground e interface corrompida.

## Objetivo

Criar um site de apresentação profissional para:

- apresentar a persona e o universo artístico;
- destacar lançamentos, videoclipes e colaborações;
- direcionar ouvintes para o Spotify;
- apoiar bookings, imprensa e parcerias;
- funcionar muito bem no celular.
